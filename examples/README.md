# Шаблон плагина

Плагин — один ES-модуль с `export default`. Он независим: редактор ничего ему
не одалживает, кроме `host`, и ничего не знает о том, что у него внутри.

`shift/index.js` — весь плагин целиком. Зависимостей у него нет, поэтому и
собирать нечего: этот файл и есть то, что кладут в реестр. Сборка нужна только
тому, кто что-то подключил и должен приехать одним файлом:

```sh
bunx vite build --config examples/vite.config.js   # → examples/dist/shift/index.js
```

Кнопки, переключатели и листы плагин рисует классами редактора
(`src/lib/ui/public-classes.ts`): они объявлены глобально под `.editor`, а
токены приходят каскадом — своего CSS для родного вида не нужно. Если он всё же
нужен, правила несут префикс `id` плагина: изоляции стилей нет, это ловится на
ревью исходников.

Свой фреймворк подключить никто не мешает — он просто приедет в бандле плагина
целиком, со своим весом и своим экземпляром.
