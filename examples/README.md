# Шаблон плагина

Плагин — один ES-модуль с `export default`. Он независим: редактор ничего ему
не одалживает, кроме `host`, и ничего не знает о том, что у него внутри.

`shift/index.js` — весь плагин целиком. Зависимостей у него нет, поэтому и
собирать нечего: этот файл и есть то, что кладут в реестр. Сборка нужна только
тому, кто что-то подключил и должен приехать одним файлом:

```sh
bunx vite build --config examples/vite.config.js   # → examples/dist/shift/index.js
```

## Свои слова

Текст плагина — его собственный. Редактор в его словарь не пишет, плагин в
словарь редактора не дотянется: `locales` уезжает в i18next редактора под
неймспейс `plugin:<id>`, и больше ниоткуда не виден.

```js
export default {
  id: 'example.shift',
  api: 1,
  locales: {
    ru: { label: 'Сдвиг', apply: 'Сдвинуть' },
    en: { label: 'Shift', apply: 'Shift' },
  },
  tool: {
    label: { t: 'label' },          // ключ в свой каталог
    title: 'Одинаково на всех языках', // или просто строка
    activate(host) {
      host.window({ title: host.t('label') });  // и в рантайме — по ключу
    },
  },
};
```

Три формы текста в манифесте равноправны: строка — одна на все языки,
`{ t: 'ключ' }` — ключ в свой каталог, `{ ru: '…', en: '…' }` — карта для
плагина, которому каталог заводить не из-за чего. Ключ, на который каталог
ничего не отвечает, — это запись без подписи: она не принимается, и в логе
сказано почему. Сырой ключ на рельсе не появится.

Язык редактор выбирает сам; плагин его не спрашивает и не переключает.

Кнопки, переключатели и листы плагин рисует классами редактора
(`src/lib/ui/public-classes.ts`): они объявлены глобально под `.editor`, а
токены приходят каскадом — своего CSS для родного вида не нужно. Если он всё же
нужен, правила несут префикс `id` плагина: изоляции стилей нет, это ловится на
ревью исходников.

Свой фреймворк подключить никто не мешает — он просто приедет в бандле плагина
целиком, со своим весом и своим экземпляром.
